Latest source work

  • Numerical admission: selected harmonic assembly and complex-arithmetic paths preserve small terms, recheck original equations and reject unrepresentable final values.
  • Payload ownership: compact and transient paths move owned values while preserving independent retained outputs.
  • Cancellation: local graph admission, node and completion boundaries cannot turn an observed cancellation into success through skip policy.
  • Selected inputs: fallback traces and direct lineage name the source actually selected, not unused alternatives.
  • Output retention: requested published results survive optional ports, cache hints and later consumers; unrequested intermediates still release.
  • Execution receipts: Orchestra condition and failure traces agree with actual publications and shared Rust controls; local API and SQLite readback retain those records.

These are scoped source checks, not a new installed binary, whole-system coverage percentage, remote CI result or durable-checkpoint guarantee. Reports retain their exact test targets, platform and exclusions.

One research journey

  1. Declare the objective, constraints, optimization metrics and stopping budget.
  2. Discover the installed capabilities and validate the model, graph and dataset contracts.
  3. Obtain caller-owned approval and execute real operator tasks through a Headless SDK.
  4. Observe known job identities; classify failure, cancellation and unknown outcomes before selecting recovery.
  5. Check result identity and numerical gates before ranking candidates or admitting another round.
  6. Export the result, lineage and limitations for replay and human review.

Research agents use Headless SDKs; Rust Agents execute admitted tasks. Workbench provides modeling, inspection and human takeover. PWDT automates the fixed GUI but is not required for Headless operation. Neither model output nor a planning report can grant execution authority.

What remains open

The October 24 local tensor readback has 13 modules, 11 paradigms, zero structural gaps, two maturity gaps, 23 evidence-grade gaps and 18 P0 gaps. Daji remains blocked. Structural success is not numerical, installed-platform or release qualification.

  • Independent numerical correlation and production acceptance for the required physical scenarios.
  • Installed desktop, update and cross-language SDK journeys with their actual platform evidence.
  • Authenticated multi-host Mesh faults, load/churn and ownership-preserving recovery.
  • Durable and typed workflow continuation under the required backend and interruption model.
