Kyuubiki contract / moxi 2.7.x

Kcore Exchange Format

A frozen, path-independent, content-addressed exchange layer for simulation models, operator graphs, results, evidence, and previews.

.kyuubiki

Editable project source, workspace state, version history, jobs, and authoring configuration.

.kcore

Portable computation output for SDKs, runtimes, stores, archives, and third-party research tools.

Container

mimetype
manifest.json
objects/<sha256-prefix>/<sha256>

Every payload is streamed, content-addressed, deduplicated, and bound by the manifest core digest. Host paths, symlinks, undeclared files, duplicate entries, and traversal are rejected.

Native workflow

kyuubiki kcore export export.json --out result.kcore
kyuubiki kcore inspect result.kcore
kyuubiki kcore verify result.kcore
kyuubiki kcore extract result.kcore --out restored-core

The Rust library and standalone kyuubiki-kcore binary own the implementation. GUI and headless SDK surfaces should bind it instead of reimplementing the format.
