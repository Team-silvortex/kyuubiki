## Repairs

1. Workflow metric validation now reads the actual scoped Elixir alias maps and derived
   function heads. Native and Elixir transport-quality opt-in terms agree without changing
   the default four-term objective.
2. The heat/thermo workflow fixture serves the two real diagnostic RPCs as well as the
   two solves; the fixture no longer assumes the obsolete two-request execution path.
3. GUI assertions respect retired authority contexts. Late PWDT saves reject rather than
   reconciling a different backend's same-ID record. Explicit source refresh starts from
   the verified record instead of reviving an invalidated draft.
4. The real-browser journal fixture snapshots message fields at initial delivery. Chromium
   148 can re-wrap a retained `MessageEvent.source` after its sender's realm is destroyed.
   The fixture now explicitly requires the captured stable WindowProxy, so it exercises
   session retirement rather than timing out on the unrelated source-rejection guard.
   Handshake and navigation waits are bounded. No production origin/session guard changed.
5. SDK canonical-hash expectations are key-sorted even with workspace `preserve_order`
   feature unification. Fixed-input mismatch selection also has deterministic key ordering.
6. The receipt-retention live fixture waits for the worker lease to drain before its next
   sequential request; a final response does not itself imply capacity has been released.
7. Native workflow restart tests verify Orchestra's durable native-result checkpoint and
   no duplicate completed work when the Agent loses its in-memory receipt. Terminal
   publication must prune the private checkpoint. The PostgreSQL continuation claim is
   partial until the revised scenario is rerun against a disposable PostgreSQL database.
8. Each Cargo audit lane may warm its own registry entries. The first lockfile's advisory
   database fetch does not populate every other lockfile's yanked-package index entries.
   Fresh-cache fallback remains bounded and does not suppress vulnerability failures.
9. Security dependencies were updated across frontend, Web and independent desktop locks:
   Next 15.5.27, Sharp 0.35.5, source-map-js 1.2.2, Bandit 1.13.1, Decimal 3.2.0,
   Rustls 0.23.46 and ZIP 9.0.5. ZIP name decoding is now explicitly fallible; bundle and
   kcore readers retain path, size, integrity and symlink validation.
10. CI runs solver tests in complementary general/material jobs, separately from service
    and SDK tests. The 42-file workflow GUI suite has three deterministic disjoint shards.
    Local runs without `KYUUBIKI_UI_TEST_SHARD` still run the full suite; invalid shard
    specifications fail rather than silently dropping files. No test is ignored to
    achieve this split.
