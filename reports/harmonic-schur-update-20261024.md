## Failures Before Repair

Two private tests and one public operator test failed before implementation.
Let `d=2^-27` and `w=2^-20`. The exact Schur coefficient
`(1-2*d+w)-(1-d)*(1-d)` is `w-d*d`. Separately rounding the square first
instead produces `w`. This difference lies outside the existing strong
cancellation trigger, so the legacy ordinary update accepts it.

The public fixture has three positive springs: root to middle with stiffness
`d`, middle to tip with `1-d`, and root to tip with `w-d`. Only the tip has a
load, equal to `w`; frequency is zero. The free matrix and RHS are
`[[1,-(1-d)],[-(1-d),1-2*d+w]]` and `[0,w]`. The zero leading RHS isolates
the coefficient error: its elimination does not perturb the tip load.

The exact tip displacement is `w/(w-d*d)`, approximately
`1.0000000000582077`. The old successful public result is `1.0`, about
`5.8e-11` relative error. The matrix has a soft mode: its infinity-norm condition
number is approximately `4/w`, about `4.2e6` for this fixture. Conditioning
amplifies a small coefficient error; this is not evidence of physical uncertainty
being eliminated or arbitrary ill-conditioned models being solved accurately.
The old result still satisfies the existing backward-residual tolerance.

The private coefficient test originally called the legacy `difference` used
by the Schur sites. It now targets the new `matrix_difference` wrapper; legacy
standalone arithmetic is intentionally retained. The dense/path and public
before/after tests exercise actual factorization, not a substituted coefficient.

## Solver Integration

A small matrix-specific wrapper requests a fused scalar update from the
existing row helper. Its local eight-epsilon rounding estimate can request
complete-expression replay; it is not a pivot tolerance or physical admission
rule. The wrapper retains exact-restoration checks when replay returns a scaled
coefficient. No second precision-policy implementation or new persistent state
is introduced.

All four production coefficient update sites use the wrapper: dense trailing
cells, ordinary path diagonals, diagonals after an adjacent pivot swap, and
the upper coefficient generated by that swap. Standalone multiplication and
legacy difference retain their existing implementation and bit controls.
Coefficient-update bits may change deliberately.

The weighted pivot constant remains `32*epsilon*size`; row weights and swaps
are unchanged. More accurate coefficients can legitimately change a borderline
pivot decision, so identical pivot histories are not promised for all inputs.
No regularized pivot, zero-clamping policy or relaxed original-equation gate
is introduced.

Subnormal coefficient policy remains fail-closed: exact quantum differences
are supported, but an irreversible fractional-quantum restoration is rejected
rather than silently changing a coupling. True overflow and invalid operands
remain errors. Already rounded elimination factors are still inputs to the
update; fusion cannot reconstruct their missing information.

The wrapper adds no matrix copy, row vector, successful-path heap allocation
or dependency. Fused arithmetic and precision checks add work and may select
more replay; this is not evidence of performance neutrality or speedup.

## Regression Coverage

Twelve new test functions cover seven private units, two public Solver tests
and three Engine integration tests:

- A bit-exact weak Schur coefficient and a complex partial-sum example where
  fusion alone loses a tail but the precision-risk rule selects complete replay.
- Dense/path solves with and without row swaps, three common binary scales
  and real/imaginary/dyadic-complex phase controls. These phase pairs keep the
  manufactured leading factors representable; they are not arbitrary phase
  invariance or general forward-error proof.
- A three-row adjacent-pivot example that generates a second superdiagonal,
  with an independently known third unknown and soft-mode response.
- Weighted pivot admission at 0.9 and 1.1 times the existing floor, with and
  without input row permutations in both factorizations.
- Exact quantized coefficients, irreversible subnormal restoration, true
  overflow, recoverable intermediate overflow and invalid operands.
- Cancellation before either replay component and at bounded pass endpoints,
  followed by fresh same-input reuse.
- Public rational references at `w=2^-18`, `2^-20` and `2^-24`, both load signs,
  all element orientations, borrowed/owned equality and finite force readback.
- Input/result byte roundtrips and Engine dispatch/workflow readback. Factor
  or result cancellation and a later frequency range error publish no successful
  result prefix; explicit repaired-input reuse succeeds.

Public displacement comparisons allow four binary64 epsilons of relative error
against independent rationally derived references. They do not assert exact
whole-solve bits. Cancellation is cooperative in-process evidence, not forced
termination or durable power-loss recovery. The public model is a small
analytical spring fixture, not independent material qualification.

## Remaining Boundary

This is bounded harmonic Schur-coefficient update hardening, not exact factorization, exact assembly or unrounded-expression division, a whole-solver forward-error certificate, independent physical qualification or durable restart.

Assembly, normalization fallback, represented factors and successive coefficient
updates still round. General non-dyadic factor errors, conditioning-aware forward
accuracy and division of the complete unrounded row expression need separate
work. Independent physical/material references, scale performance, installed/SDK
journeys and persisted recovery are not qualified here. No qualification
threshold or release grade is promoted by these local controls.
