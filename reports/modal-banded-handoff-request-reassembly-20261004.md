# Modal candidate request reassembly and material boundaries

October 4, 2026. Local macOS ARM64 source overlay on commit `dc5647af`
(`daji 3.4.6`); Cargo and shipping/development manifests remain 3.4.5.
Rust toolchain 1.88.0. This follows the
[checked order handoff campaign](modal-banded-checked-order-handoff-20261004.md).

This is test-only rebuilt-request evidence, not production modal admission.
Twenty-four freshly rebuilt numbering layouts retain exact candidate results.
Sixteen of eighteen material changes publish independently checked candidate
results; two small-coordinate layered cases remain rejected even by the
separate full physical strategy portfolio. No residual or norm gate is relaxed.

The later [inward-chart candidate follow-up](modal-material-inward-chart-reliability-20261004.md)

promote production recovery recorded here.

## Request reconstruction scope

The retained inputs contain 128 horizontal forward-chain members and 129 nodes,
with axial motion restrained everywhere and transverse motion/rotation restrained
only at the left end. Graded and layered profiles each use coordinate scales
1, 1e14 and 1e-10. Only a single mode is requested.

Each layout is rebuilt from request JSON, not a simultaneous permutation of
an existing matrix/eigenvector. Keys 0, 1, 7 and 113 cover original order,
reversed nodes and members, and two deterministic shuffles. Node IDs and material
data follow the renumbering. A private test harness validates the topology,
sorts the physical chain and remaps endpoints, then independently assembles
the operators/masses, computes the Jacobi seed, retains the true failed
four-step refinement pair and performs banded candidate initialization.

This harness does not exercise production `NodeOrder`, admit arbitrary topology
or replace production request validation. Its explicit exclusions include
otherwise valid frames, such as an opposite member orientation or a second
restraint. Those inputs are unsupported by this prototype, not necessarily
invalid under the public frame contract.

The normalized stage remains ranked grid-norm then reverse. Its checked strategy
tag selects one independently constructed/certified physical fit. The result is
expanded to all three public degrees of freedom per node and restored to original
request numbering, including `free_dofs` and restrained positive-zero coordinates.
The original request accompanies the serialized result. The separate reference
then reconstructs stiffness/mass from that original-numbered JSON.

All 24 layouts preserve exact frozen-root bits, request-derived banded seed,
accepted order tags, factor/certificate counts and mapped physical shape bits.
Six fresh unrenumbered baselines are additional controls, not 24 new geometries.
Total mass permits 1e-14 relative accumulation error after member order changes.

## Changed material controls

Each of the six base geometries also receives three actual material changes:
uniform `(Young multiplier, density multiplier)` values `(4, 1)`, `(1, 4)` and
`(16, 4)`, with request layout key 7. These are eighteen new parameter inputs,
not binary-amplitude changes to a retained vector. Every route rebuilds its
request, operators, root and seed from scratch.

For the sixteen accepted inputs, both the one-fit handoff and independently
ranked physical route publish the same complete result. Every publication passes
the unchanged 1e-8 physical residual and strict 1e-10 unit-norm gates, plus the
original-numbered independent JSON reference. Additional material relations are:

- Eigenvalues scale with `Young / density`, within 1e-12 relative error.
- Frequencies scale with `sqrt(Young / density)`, within 1e-12 relative error.
- An independently computed wide banded LDL inertia bracket midpoint obeys
  the eigenvalue ratio within 1e-13. Its width/root is below 1e-14.
- Total mass follows density within 1e-14 relative accumulation error.
- Physical eigendirections, compared modulo global sign with a unit-direction
  view only, differ by less than 1e-10 in L2 norm.

The direction comparison does not renormalize published output, modify either
checker or supply an oracle seed. A global eigenvector sign reversal is allowed
only in this comparison; numbering controls still require exact mapped bits.
One observed material eigenvalue ratio differs by one floating-point rounding
unit, so bit-exact scaling is not claimed for changed materials. The largest
observed root ratio error is 2.220446e-16, inertia ratio error 2.220446e-16,
and sign-invariant direction difference 2.129998e-13.
The finite wide-arithmetic inertia calculation is a cross-check, not an interval
enclosure, formal proof or independent experimental material validation.

## Unresolved physical cases

Layered geometry at coordinate scale 1e-10 rejects the density-times-four cases
`(1, 4)` and `(16, 4)` after its internal Reverse proposal has been accepted.
Three independently rebuilt cold routes are compared for each rejected request:

| Physical route | Actual fits on each rejected input | Portfolio certificate receipt | Outcome |
| --- | ---: | ---: | --- |
| checked-order handoff | 1 | 4 | rejected |
| independent grid-norm then reverse | 2 | 8 | rejected |
| independent full reverse/natural/grid-norm | 3 | 11 | rejected |

All report bounded-policy exhaustion with zero norm rejections. The best measured
physical residual on all three routes is 1.0241712231970532e-8 for both inputs,
above the unchanged 1e-8 gate. Actual physical operator callbacks are separately
observed as 4, 8 and 11, matching the respective portfolio receipts in these
cases. Simply trying another ordering does not recover them. No partial result
is returned.

The diagnostic full route is started with a new request/operator/seed pipeline,
not appended to a live failed handoff or installed as production retry behavior.
Each failure leaves the changed request unchanged; the fresh original material
task then reproduces its healthy baseline exactly. The tests deliberately retain
two unresolved results. Passing this regression means these boundaries are
observed and asserted, not that the material solve problem is fixed.

A separate reference-only control maps the already accepted original-material
direction by node ID into a newly rebuilt changed-material request. It uses the
new request's actual frozen root, masses and physical operator, then original
numbering restoration and independent JSON stiffness/mass reconstruction. Both
controls pass with physical residual 8.589526588689863e-9. The frozen roots are
6.937656641391256e-9 for `(1, 4)` and 1.110025062622601e-7 for `(16, 4)`.

The control direction never initializes a candidate search and is not used to
recover either failed route. It proves that an admissible f64 unit physical
direction exists for these two specific requests; it does not provide a general
construction or runtime method. This points to a candidate-generation/search
limitation, not a demonstrated impossibility under the strict gate. Sixteen
successful algorithm outputs and two reference-only witnesses must remain
separate counts.

## Rejection and cancellation controls

Nine malformed or prototype-unsupported request variations are declined before
candidate execution: multimode, invalid endpoint, free axial motion,
nonhorizontal geometry, missing member, opposite member orientation, duplicate
member pair, coincident coordinates and an additional restraint. Swapping valid
members remains accepted and reproduces the baseline.

Cancellation at the actual final original-node restoration checkpoint returns
no result. A new complete request run then exactly reproduces the baseline,
including physical JSON checks. This is source-tree test-harness restoration
recovery, not installed App, Agent process or Headless study recovery evidence.
