SQLite workstation

An embedded database keeps setup simple for single-machine work.

  • No separate database service
  • A good default for local design iteration
  • Stores data in the configured .sqlite3 file

Cloud ready

PostgreSQL deployment

Use PostgreSQL for shared environments, hosted services, and multi-node work.

  • Supports distributed orchestration
  • Shared project and history storage
  • Requires DATABASE_URL
