What this line means

  • Keep the 2.x baseline contract-driven instead of returning to prototype sprawl.
  • Prefer confidence and coherence over raw feature-count inflation.
  • Expand capabilities only when they strengthen the industrial baseline.

Current 2.7 checkpoint

  • Cohesive, connector, truss, and plane-stress triangle elements now share one bounded equilibrium workflow.
  • Explicit control histories cover cyclic and non-proportional displacement paths.
  • Constitutive history commits only after convergence and failures retain the prior state.
  • Solver, Agent RPC, and workflow tests protect the same protocol representation.
  • Wider host elements, sparse assembly, and advanced continuation remain explicit future work.
